# 项目素材目录说明

各目录用途（SPEC会引用这些路径）：

| 目录 | 放什么 | 示例 |
|:----|:----|:----|
| `images/` | 游戏截图/封面/Hero图 | header.jpg, screenshot-1.jpg |
| `logo/` | 站标全套 | favicon.ico, apple-touch-icon.png, android-chrome-192/512.png |
| `videos/` | 官方视频（或视频ID记录） | 官方预告片ID sRdZ9L37bJ4（存youtube_id.txt） |
| `素材/` | 文字素材（md文件） | 首页素材.md, 各关键词素材.md |

**使用规则：**
- 图片/logo/视频文件放对应目录，文件名用英文小写+连字符
- 素材md文件放 `素材/`，文件名格式：`nmrih2 <词>.md`
- SPEC写死路径，AI按路径引用
