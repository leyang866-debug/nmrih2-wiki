# No More Room in Hell 2 — 1.0状态评测补充（玩家实测）

> 来源：YouTube "Is It Enough? The State of NMRIH2 as of the 1.0 Armageddon Update"（用户手动提取）
> 时间：1.0发布后（2026-08-15提取）
> 分级：玩家经验（参考级）

## 1.0状态要点（玩家评测）
- 玩法核心：PVE合作+目标导向（不是纯杀丧尸），任务多样（恢复电力/找医疗文件/撤退）
- Survival模式：3个区域守3波尸潮，活着回来
- Solo模式：可在Objective和Survival地图练习（无成长/无永久死亡）
- 角色成长：Responder可强化，死亡损失在（Permadeath）
- 搜刮导向：地图边缘游走搜刮，资源稀缺是特色
- 1.0难度调整：简单更简单/难更难，新手压力降低
- Permadeath：80%+ Responders会失败（玩家观察）
- 新任务：特定方式杀丧尸（如用霰弹枪击杀），随机化
- 脱困机制：新增unstuck按钮（卡住脱身），代价2000 credits（回出生点+变穷）
- **主机版：目标60 FPS，平台分辨率缩放+额外性能选项**
- **Series S可达HD分辨率**
- 优化：0.9版好，1.0更好；EA初期优化问题已解决
- 匹配：Lobby Backfill等改进，运气成分降低
- 武器：1.0重新梳理（口径/新武器）
- **8000+ bug修复**（1.0相比EA早期）
- 期待：1.0后更多地图/武器
